# Examples

- `centroids/control_RM_halfturn_IV.csv` — Dragonfly centroid export of epithelial nuclei from one cochlear
  half-turn (IV) of Reissner's membrane in a control ear. Run
  `python scripts/order_and_measure.py examples/centroids/control_RM_halfturn_IV.csv -o demo --plot`.
- `validation_annotations/` — model output and two anonymised human annotations (investigators 2 and 3) of the
  five-image validation set (see `docs/VALIDATION.md`). Semicolon-separated; `PosX`/`PosY` in µm; `PosZ` identifies the image.
